# Counter-rotation

When a parent rotates, its children rotate with it. To move something around a circle while keeping it upright, rotate the child the opposite way at the same speed. The two cancel out.

[[orbit-animation]] runs the same [[css-keyframes]] animation in `reverse` on each planet, so labels always read normally.

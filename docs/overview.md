Think of Frontend Explore as a field guide to interactions. Each entry is a living specimen you can poke at, with notes on where it lives, what it pairs with, and how to keep it safe for everyone.

## What it is

Frontend Explore is a small library of hand-built interaction patterns for React and TypeScript. Every pattern has a live playground, its real source code, a walkthrough of how it is built, and notes on when to use it and when not to.

The goal is pages that feel crafted, not generated. So each pattern comes with judgment as well as code: a "use when", an "avoid when", what it pairs well with, and what it clashes with.

## Who it is for

Designers and builders working on any kind of project. You can browse the patterns yourself, or let an AI coding tool pick and build them for you (planned: the plugin).

## Two starting points

**A blank page.** You have no design system yet. Pick one signature interaction, then let the rest of the page stay calm around it.

**An existing product.** You already have components, colors and type. Every pattern styles itself through CSS custom properties, so it can take on your product's look instead of overriding it. See [[css-custom-properties]].

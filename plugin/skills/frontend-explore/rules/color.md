# Color

- One background family, one text color with two quieter steps (muted, faint), and one accent. Add a second accent only for a clear job, such as focus or links.
- Use the accent sparingly: the main button, the active state, the signature moment. If everything is accented, nothing is.
- Check contrast: body text at least 4.5:1, large text and UI parts at least 3:1.
- Focus rings must be visible on every background. A bright 2px outline with an offset works.
- In an existing product, use its tokens. Do not add new colors.
- Define colors as CSS custom properties so patterns and the page share them.

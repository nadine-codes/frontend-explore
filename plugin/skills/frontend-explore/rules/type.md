# Type pairing

- Use two families at most: one for headings and body, one mono or serif for accents such as labels, numbers or code.
- Make the heading scale bold: a hero heading of 3 to 5 times the body size reads as designed. Timid headings read as a template.
- Tighten big headings (letter spacing about -0.02em to -0.035em, line height 1 to 1.1). Leave body text at 1.5 to 1.7 line height.
- Body text 16px or more. Keep lines between 45 and 75 characters (about 640px at 16px).
- Small uppercase labels need letter spacing (about 0.1em to 0.14em).
- Load fonts with `display=swap` and only the weights you use.
